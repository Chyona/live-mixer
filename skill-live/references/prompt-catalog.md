# 提示词目录

提示词是 LLM 选片的**系统提示词**。技能内置 4 套只读提示词（与客户端
`PromptCatalog` 一致），完整内容在
[`scripts/prompts.py`](../scripts/prompts.py)，
可用 `python3 scripts/livemix.py prompts show "<名称>"` 查看。

| 名称 | 来源 / 备注 | 编辑时间 | 适用场景 |
| --- | --- | --- | --- |
| **财经类直播** | 适用于金融行业；从 live-mixer 后端导入 | 2026-08-26 14:44:41 | 财经、宏观、投资、行业研究类直播 |
| **服装切片 · 黄金3秒定稿** | 服装切片历史版本 · 2026-08-28（当前版） | 2026-08-28 14:33:12 | 服装带货；先抽 1–5 秒黄金钩子，再补四段叙事 |
| **默认提示词** | 服装切片历史版本 · 2026-05-05 | 2026-05-05 22:45:02 | 服装带货；结构化模板 + 合规预筛 + 14 种爆款开头 |
| **服装切片 · 基础版** | 服装切片历史版本 · 2026-04-02 | 2026-04-02 14:09:02 | 服装带货；四段叙事、剔除静音/重复/残句 |

> 客户端「默认提示词」指向 **2026-05-05 的服装切片结构化模板**，不是「基础版」。

---

## 1. 选片输出契约

无论使用哪套系统提示词，用户消息都会追加固定输出格式（见
[`llm.py`](../scripts/llm.py)）：

```
## 视频ASR
[0] (开始秒 - 结束秒) 文本
[1] ...

## 输出格式
- 仅输出一个 JSON 对象，不要输出任何额外文字、注释或角色标记。
- 字段：
  - indices：选中的句段索引（整数数组），按原顺序递增。索引必须来自 视频ASR 列表的行号（从 0 开始）。
  - title：短视频标题，2～12 个汉字。
  - description：短视频内容介绍，128 个字以内，概括成片核心观点。
  - topics：短视频话题字符串数组，共 2～6 个；每个话题 2～12 个汉字，不要带 # 号。
- 标题、介绍与话题须依据选中句段撰写，不得编造 ASR 未出现的事实。
- 示例：{"indices":[2,5,9,13],"title":"利率上行的真相",...}
```

解析容错：`indices` / `indexes`、纯索引数组、代码块围栏、JSON 前后解释文字。
首次解析失败会用「严格 JSON」前缀再试一次。

## 2. 各提示词的侧重点

### 财经类直播

- 合规红线：不得出现保证收益、稳赚不赔、内幕消息、推荐买入/卖出、抄底逃顶；
  避免引流、具体理财产品名、绝对化宣传、敏感宏观、具体价格承诺；
- 只围绕同一核心主题；剔除闲聊、杂音、重复、残句；
- 讲解流程：开场钩子 → 背景/数据 → 核心洞察/逻辑推演 → 结论/认知收尾；
- 叙事角色：`hook / context / insight / action`；
- 成片总时长 3–8 分钟；
- 标题 2–12 字、介绍 ≤128 字、话题 2–6 个。

### 服装切片 · 黄金3秒定稿（当前版）

- STEP 1 合规预筛（硬门槛）：引导类、绝对化、虚假夸大、第三方平台、
  敏感营销、封建迷信、知名品牌、具体价格承诺；
- STEP 2 锁定同一商品并剔除无效内容；
- STEP 3 只提取 opening：用「陌生用户独立测试」筛选 1–5 秒钩子，
  按停留欲望、信息缺口、用户利益、表达冲击、独立可理解性评分；
- STEP 4 补齐四段叙事：`opening → product → selling → closing`，
  index 必须严格递增；
- STEP 5 只通过增删/替换控制时长，不拉长 opening；
- 提供 13 类钩子示例与 `NEGATIVE` 清单。

### 默认提示词（2026-05-05）

- 结构化模板 + 合规违禁词预筛；
- 服装四段叙事：`opening / product / selling / closing`；
- 成片时长 25–120 秒，优先 25–60 秒；
- 14 种爆款开头模板（痛点、悬念、视觉冲击、情感共鸣、数据、反转、
  直接展示、互动、热点、场景、权益紧迫感、对比、权威、挑战）。

### 服装切片 · 基础版

- 最简版本：剔除无讲话、重复叙述、残句；
- 按「开头/引入 → 产品展示 → 核心卖点 → 结尾/转化」择优排序；
- 适合作为测试提示词或二次改写的起点。

用户明确指定提示词时以用户为准；没有指定时使用配置 `ai.defaultPrompt`
（默认「默认提示词」）。

## 4. 自定义提示词

```bash
# 文件方式（.md / .txt / 任意文本）
python3 scripts/livemix.py clip --input demo.mp4 --prompt ./my-prompt.md

# 直接传含换行的文本
python3 scripts/livemix.py clip --input demo.mp4 --prompt "你是……"
```

自定义提示词只需要写「选片偏好 / 合规要求 / 叙事结构」，不要写输出格式
（流水线会统一追加）。如果提示词要求输出额外字段，模型可能偏离固定 JSON，
导致首次解析失败并触发严格模式重试。

提示词中的规则应尽量可执行：

- 选什么：主题、内容类型、时长、叙事顺序；
- 不选什么：闲聊、重复、违规表述、残句；
- 合规红线：行业相关禁用词与承诺；
- 元数据要求：标题/介绍/话题的语气与长度（最终仍会被脚本截断与清理）。

---

## 5. 事实与合规

- 成片字幕严格来自 ASR 原文，不做改写；
- 标题、描述、话题由模型依据选中句段生成，不得编造 ASR 未出现的事实；
- 财经与服装提示词都包含合规条款，但最终发布前仍应由人复核：
  平台规则、广告法、证券投资咨询相关规定、品牌与版权授权；
- 只处理你有权使用的直播与视频素材。
