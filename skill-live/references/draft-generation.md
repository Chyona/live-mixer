# 剪映草稿生成规则

对应实现：[`scripts/pipeline.py`](../scripts/pipeline.py)
与 [`capcut.py`](../scripts/capcut.py)；
客户端基准：`LiveClipService::createDraftForProject` + `CapCutMateClient`。

一条成片对应一个剪映草稿。执行顺序固定为：

```
裁剪切片 → 上传切片 → 创建草稿 → 添加视频（主轨/倍速/转场/特效/滤镜/贴纸/去重图片）
→ 添加中文字幕 → 音效 → BGM → 英文轨 → 保存草稿记录
```

---

## 1. 画布

- 取**第一段**成功探测到分辨率的切片；
- 宽高比更接近 `1080/1920` → `1080×1920`（竖屏）；否则 `1920×1080`（横屏）；
- 探测失败或宽高 ≤0 → 默认 `1920×1080`；
- 画布尺寸通过 `create_draft` 的 `width` / `height` 提交。

---

## 2. 主视频轨

每个切片先 `upload_file`，再按累计播放时长铺到同一条轨道。

`add_videos` 请求：

```json
{
  "draft_url": "<create_draft 返回值，原样透传>",
  "video_infos": "[{\"video_url\":\"https://...\",\"start\":0,\"end\":4500000},{\"video_url\":\"https://...\",\"start\":4500000,\"end\":9000000}]",
  "scene_timelines": [{"start": 0, "end": 3103000}, {"start": 3103000, "end": 6206000}],
  "scale_x": 1.0,
  "scale_y": 1.0
}
```

要点：

- `video_infos` 是 **JSON 字符串**；`scene_timelines` 是数组；
- `start/end` 单位微秒，表示切片（源素材）在草稿时间轴上的累计区间；
- `scene_timelines` 与 `video_infos` 一一对应，表示变速后的播放区间；
- 倍速 = `(end - start) / (scene_end - scene_start)`；
- 只有**所有**片段都有 scene 区间时才提交 `scene_timelines`；1.0× 不提交；
- 转场挂在**左段**上：`transition` + `transition_duration`（微秒）。

平台去重开启时，缩放是**请求级**参数，所以默认一段一次 `add_videos`，
每段独立随机 `scale ∈ [1.0, 1.1)`；带转场的一对相邻片段必须在同一请求内提交，
共用同一个随机缩放值。

### 转场

- 仅当开关开启时；
- 候选：相邻两段的播放时长都 **> 800ms** 的组合；
- 随机挑一对、随机挑一种转场，时长固定 `800000` 微秒；
- 无合格组合时跳过。

候选池（35 种）：

`叠化、叠加、闪黑、闪白、相片切换、翻页、左移、立体旋转、右移、卡片弹出、
上下翻页、上移、下移、旋转圆盘、立体翻转、推近、拉远、向左、向右、抖动、
吸入、放射、震动、向下、向上、顺时针旋转、逆时针旋转、向右下、向左下、
向下拖拽、向下抖动、旋转震动、扭曲弹动、眨眼、流光`

## 3. 字幕

### 3.1 断句与时间

只使用 LLM 选中的 ASR 句段。每个句段：

1. 按标点拆句：
   `，。！？；：、,.!?;:…—\n`；
   数字之间的 `. , : ： ， -` 不拆（如 `29.3`、`1:30`、`1,000`）；
2. 去掉标点与多余空白，保留英文单词之间的空格；
3. 单条超过 15 个字时均衡拆成多条（33 字 → 11/11/11）；
   英文单词、数字、百分号（`100%`）等不可从中间截断；
4. 每条字幕的绝对时间：
   - 优先用 ASR `words` 逐字时间线：在词流上逐字匹配，标点/空格跳过；
     一个词包含多个字时按字符位置线性插值；
   - 任何一处文字对不上 → **整句**退回按去标点后的字数比例分摊；
   - 相邻词的几毫秒重叠会把本条起点吸附到上一条结尾；
5. 映射到成片时间轴：
   - 字幕起点/终点先裁剪到当前切片区间；
   - 与原区间相对时间除以倍速；
   - 加上该切片在成片上的累计偏移；
   - 终点不超过切片播放结束；
   - 跨切片累计做重叠保护：本条起点 ≥ 上一条终点；
   - 最终时长 <50ms 的字幕丢弃。

### 4.4 平台去重

- 主轨每段随机放大 `1.0–1.1`（见主视频轨）；
- 从素材服务随机取 **5 张**带「去重」标签的图片；
- 每张显示 **20 秒**（成片更短时钳到总时长）；
- 透明度 `0.03`，缩放 `1.0`，原始尺寸（不写宽高）；
- 位置随机：x ∈ `(-1080, 1080)` 开区间，y ∈ `(-1920, 1920)` 开区间；
- 起点在 `[0, 总时长-20s]` 内随机；
- 每张必须单独调用 `add_images`（transform 是请求级参数）；
- 叠层顺序：在主视频之后、字幕之前，保证不被主轨遮挡、也不遮字幕。

```json

 "scale_x":1.0,"scale_y":1.0,"transform_x":-321,"transform_y":876,"alpha":0.03}
```

## 5. 自动音效（SFX）

1. 从素材服务 `GET /openapi/assets/v1/sfx?page=1&page_size=100` 拉取目录；
2. 按内置资源 ID 顺序匹配 13 个音效；缺失的跳过；
3. 用大模型稀疏选点：

系统提示要求：宁少勿多（约 5 处/分钟）、只对关键卖点/数字结论/场景氛围/
互动号召加、语义必须匹配 `usage_hint`、没有合适匹配就返回空数组。

用户提示列出每条字幕 `[i] (start s - end s) 文本`，并给出建议上限。

4. 建议数量：

```python
budget = clamp(round(captions_end_ms / 60000 * 5), 0, 8)
```

5. 有效字幕索引按时间顺序取前 `budget` 条；
6. 音效起点 = 对应字幕起点，时长 = 素材服务返回的 `duration_ms`；
   结束时间超出成片时间轴的整条丢弃；
7. 同一 URL 在时间轴上重叠 → 只保留先出现的一条；
8. 同一批 `add_audios` 内不得有时间重叠，重叠条目分批调用；
9. 音量 `0.1`，`duration` 字段随请求提交。

## 6. 自动 BGM

- 素材服务 `GET /openapi/assets/v1/bgm/random?limit=1`，随机一首；
- 时长优先用接口返回的 `duration_ms`，缺失时 `ffprobe` 探测音频 URL；
- 成片比 BGM 短 → 截断为一段；
- 成片比 BGM 长 → 按整首时长循环铺轨，末段仍用同一 URL 铺满剩余时长：

```python
position = 0
while position < video_duration:
    end = position + min(bgm_duration, video_duration - position)
    add_audio(url, position, end, volume=0.1)
    position = end
```

- 音量 `0.1`；
- 写入顺序：先音效、后 BGM，保证音效轨在 BGM 轨之前。

## 7. 中英文双字幕（默认关闭）

开启后：

1. 只翻译含中日韩统一表意文字（CJK）的中文字幕；
2. 一次请求批量翻译，模型同 `qwen3.8-flash`，`temperature=0.1`；
   `max_tokens = clamp(2000, 条数×160, 8000)`；
3. 输出 `{"translations":[{"index":0,"text":"..."}]}`；
4. 以下译文丢弃：空、仍含中文、与原文相同（忽略大小写）；
5. 英文样式：字体 `Inter-SemiBold`，字号 = 中文字号 − 2（最小 5），
   颜色/描边/动画沿用中文样式；
6. 英文位置（画布中心为原点，y 向上）：

```text
中文行高 = 中文字号 × 5 px
英文行高 = 英文字号 × 5 px
中文中心 = -中文 transform_y / 2
英文中心 = 中文中心 + 中文行高×中文行数/2 + 25 + 英文行高/2
英文中心不超过 画布高度/2 − 10 − 英文行高/2
英文 transform_y = -2 × 英文中心
```

单行中文 + 单行英文、中文字号 8 → `transform_y = -920`。

7. 不同 `transform_y` 的字幕分组多次 `add_captions`；漏译/写轨失败不影响中文轨。

## 8. 保存草稿记录

草稿生成后写入 SQLite `clip_drafts`：

| 字段 | 值 |
| --- | --- |
| `draft_id` / `draft_url` | `create_draft` 返回值 |
| `title` | LLM 标题（空则「直播切片」） |
| `description` | LLM 描述 |
| `tags` | LLM 话题；为空时 `["直播切片"]` |
| `source_start_ms` / `source_end_ms` | 第一条区间起点 / 最后一条区间终点 |
| `duration_ms` | 成片播放轴累计时长（已计倍速） |
| `downloaded_path` | `download-draft` 成功后写入本地目录 |

此时**不会**下载草稿文件；用户点击「导出到剪映」等价操作时才调用
`download-draft`，流程见 [export-and-download.md](export-and-download.md)。
